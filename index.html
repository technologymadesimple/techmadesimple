About This Project

Technology helps people stay connected, informed, and independent. But keeping up with new devices and platforms can feel overwhelming — especially without guidance.

This project is a student-led initiative to provide simple, friendly guides for learners of all ages. Whether you've never used a computer before or just want to feel safer online, you're in the right place.

How It Works

01 — Pick a path

Choose the topic that matters most to you right now. You can always come back and try others.

02 — Watch or read

Each lesson has a short video and a written guide. Use whichever feels easier for you.

03 — Practice

Try the interactive tools to test what you've learned — and build real confidence.

Where would you like to start?

Pick the path that sounds most like you. Each one has a short set of lessons, plus tools to help you practice.
